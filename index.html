キーバインド

よく使う操作のキーバインドを設定します

ペイン操作

デフォルト% (縦分割), " (横分割)
Vim スタイル| (縦分割), - (横分割)
直感的h (縦分割), v (横分割)
ターミナルアプリ風d (縦分割), D (横分割) — Cmd+d 風

追加機能

Vim スタイルのペイン移動h,j,k,l でペイン移動
Vim スタイルのペインリサイズH,J,K,L でペインサイズ変更
設定リロードprefix + r で設定再読み込み
Vi モードコピーコピーモードで vi キーバインドを使用
ペイン入れ替えprefix + { / } でペインを入れ替え
ペイン同期prefix + S でペイン同期切り替え
ウィンドウ移動Shift+左右矢印でウィンドウ切り替え
タブ操作prefix + t で新しいウィンドウ（タブ）を作成
セッション管理prefix + ( / ) でセッション切り替え
レイアウト切替prefix + Space でレイアウトを順次切り替え
ペインズームprefix + z でペインを最大化/復元
ペイン/ウィンドウを閉じるprefix + x / X で確認なしにペイン/ウィンドウを閉じる
画面クリアprefix + C-l で画面とスクロールバックをクリア
